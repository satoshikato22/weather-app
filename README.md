# 天気予報アプリ

アプリを起動するには、ファイルをダウンロード後にターミナルでnpm installを実行し、必要なパッケージをダウンロードする必要があります。
App.tsx内のAPIのURLはweatherapiのアカウントで取得したものに変更してください。

##  アプリケーションの概要
都市名を入力し、Get Weatherボタンを押下すると、現在の天気や温度の情報を出力されます。
